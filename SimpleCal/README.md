# SimpleCal

给小学生使用的离线口算工具：自由练习、算术闯关、每日练习、专项训练、分步提示、错题本、学习记录、积分商店，以及多学生档案和 JSON 备份。**双击 `口算练习.html` 即可打开**，不需要安装、不需要服务、不需要联网。发给别人时只需复制这一个 HTML 文件。

## 学生档案与备份

页面顶部显示正在记录的学生，点击「切换学生 / 备份」进入管理页。全部功能使用浏览器本地存储，不需要数据库、账号、服务器或网络。

### 多名学生

- 最多保存 20 名学生，每名学生有独立编号、昵称（1～20 字）和 8 种可选头像。支持创建、切换和修改昵称/头像；手动创建和改名不能与其他学生重名。
- 积分、每日奖励领取状态、通关进度、错题、学习统计、主题、自定义奖励和兑换记录全部独立。新学生从空白记录开始；自由练习的出题设置属于当前页面，不作为学生档案的一部分。
- 旧版单人数据自动归入「默认学生」，首次保存时写入新的多学生存储，原有单人存储键保留。已有积分、主题、奖励、关卡和学习数据继续使用。
- 切换前若有未完成练习，会提示确认。已提交答案会保留，未完成的一组不会恢复作答。
- 每个已打开的标签页保留自己的学生选择，另一个标签页切换不会改变正在答题的学生。新打开或刷新后的页面采用最近一次保存的学生选择。
- 备份替换会更新档案修订标记；仍在其他标签页中的旧练习不能继续向被替换后的档案提交答案，需退出这组后重新开始。
- 学生切换用于区分记录，不设密码，也不构成账户隐私隔离。

### 导出备份

1. 进入「切换学生 / 备份」。
2. 选择「备份当前学生」或「备份全部学生」。
3. 浏览器下载 `SimpleCal备份-学生昵称或全部学生-日期.json`，请确认文件已保存。

备份包含所选学生的昵称、头像和完整学习档案。复制到 U 盘或另一台电脑后可以恢复。HTML 程序文件不包含浏览器里的学习数据，单独复制 HTML 不会带走档案。备份与浏览器存储是独立副本，建议定期导出并妥善保管。若全部备份超过 10 MB，请分别备份每名学生。

### 从备份恢复

1. 点击「从备份恢复」并选择 JSON 文件（最多 10 MB）。
2. 程序校验备份格式、版本和学习数据，再展示学生昵称、头像、积分、通关数、答题数和错题数。
3. 默认选择「导入为新学生」：已有学生不变，同名自动增加「导入」后缀，导入后切换到首名新学生。
4. 只有包含一名学生的备份可以选择「替换当前学生的学习数据」。确认按钮会显示目标昵称；替换会覆盖该学生的全部学习数据，保留其编号、昵称和头像，其他学生不受影响。替换前建议先备份当前学生。
5. 核对后点击确认。取消、格式错误、超过学生上限或保存失败均不会改动已有档案，保存失败时可恢复存储后重试。

导入不合并积分或答题历史，也不自动匹配学生编号。浏览器清理数据、换浏览器或换设备后，需要手动导入备份；没有自动跨设备同步。本地数据损坏导致保护性停写时，可在另一个浏览器中导入已有备份恢复。

## 算术闯关

- 12 个关卡，依次学习加法、减法、20 以内加减、九九乘法、表内除法、百数加减、两步运算、乘除混合、四则和括号。
- 每关 10 道不重复的题，通常答对 8 道通关，最后一关需答对 9 道。不计时。
- 每题提交一次答案，再进入下一题；支持键盘 Enter 和全角数字。答错后显示正确答案，结束时集中回顾错题。
- 通过后解锁下一关。**首次通关奖励 `20 + 5 × (关卡编号 − 1)` 分**，即每关 20～75 分，全部首次通关共 570 分。
- 已通过的关卡可以重玩并更新最好成绩，但不重复发放积分。
- 离开未完成的挑战前会提示；未完成的一组不能继续作答，但已提交的答案、错题和学习统计即时保存；已获得的积分和通关记录不受影响。

## 学习中心

从顶部「学习中心」进入每日练习、专项训练、错题本和学习记录；闯关首页也提供每日练习快捷入口。

### 每日练习

- 每组 10 道不重复的题，新题采用当前下一关的难度；全关通过后采用最后一关难度。
- 有待巩固错题时，最多穿插 3 道；其余为新生成的题。每日练习不会解锁关卡。
- 不计时、不设通关正确率，完成全部题目并点击「查看结果」后奖励 **10 积分**。同一天重复练习会记录成绩，但不重复发分。
- 日期按本机日历计算；跨午夜完成时，以完成当天结算。已经领取过的日期及其之前日期不会再发奖励，避免时钟回退造成重复结算。
- 每次提交立即显示反馈；结束时可以查看本组错题、再练一组或返回学习中心。

### 专项训练与分步提示

当前提供两个专项，每组 10 道不重复的题，不要求先通关：

| 专项 | 题目范围 | 讲解方法 |
| --- | --- | --- |
| 20 以内进位加法 | 两个一位数相加，和大于 10；36 道合法题 | 凑十法：如 `8 + 7`，把 7 分成 2 和 5，先算 `8 + 2 = 10`，再算 `10 + 5 = 15` |
| 20 以内退位减法 | 十几减一位数，个位不够减；36 道合法题 | 平十法：如 `13 − 8`，把 8 分成 3 和 5，先算 `13 − 3 = 10`，再算 `10 − 5 = 5` |

- 从学习中心的「专项训练」选择知识点，也可从每日练习页的推荐直接开始。
- 符合这两个专项的题，无论出现在闯关、每日练习、专项还是错题重练，都能查看计算提示。其他题型暂不提供分步讲解。
- 点击「给我一点提示」先看拆分方法，再点击「看下一步」逐步展开计算，直到第三步给出最终结果；下一题会重新收起提示。
- 答题前查看任何一步提示，本题会标记为借助提示。答对仍计入总体正确率，但不用于薄弱项推荐，且会重新累计该错题的连续独立答对次数。作答之后查看方法只作回顾，不改变已经保存的答题记录。
- 专项答错会进入现有错题本，答题与完成记录进入学习统计，记录中显示专项名称和使用提示的题数。
- 专项练习不奖励积分、不解锁闯关。练完可继续相同专项或返回专项列表。

### 薄弱项推荐

- 每名学生分别记录本次更新后的专项相关作答，包括其他练习中符合专项定义的题。旧版总体正确率、旧错题次数不会被推算为专项表现。
- 保留最近 100 条专项相关答题证据；每个专项参考近 14 个本地日历日内、最近 20 次**未使用提示**的作答，排除未来日期。
- 不足 10 次时提示先试一组，不判断是否薄弱；达到 10 次且正确率低于 80% 时建议巩固；达到 80% 时显示近期表现稳定。
- 每日练习页展示建议及一键练习入口，专项列表显示样本数和答对数。这是帮助选择练习的简单规则，不是能力评定。
- 专项证据、提示使用情况和专项完成记录随学生档案保存、切换和备份。旧版备份可直接导入，新字段自动补为空，不改变原有记录。

### 错题本

- 闯关、每日练习、专项训练、错题重练中的错误答案会立即保存；同一道题合并记录，显示正确答案、最近错误答案、错误次数和最近练习日期。
- 支持筛选待巩固、已掌握和全部错题。每次显示 30 题，可继续展开。
- 一键重练最多 10 道待巩固题，优先选择错误次数多的题。连续独立答对 **3 次**即标记为已掌握，使用提示会重新累计；再次答错会重新加入待巩固。
- 重练本身不奖励积分；每日练习中穿插的错题、专项中遇到的原错题也会更新掌握状态。
- 最多保留 500 道错题；超过时优先淘汰较早的已掌握题，没有已掌握题时淘汰最早收录的题。

### 学习记录

- 展示累计答题数、正确率（含借助提示后答对）、近 365 天练习天数、连续练习天数和近 7 天正确率。
- 最近 7 天图表显示每天的答题数和正确率，加减乘除分别统计；一道混合题会计入它包含的每种运算，同种运算在一道题里只计一次。
- 保留最近 100 组完成记录，包括练习类型、日期、正确率和用时。用时按开始到完成的时间计算，包含中途停留，不作为限时要求。
- 每日明细保留 365 天，累计答题数和各运算累计统计持续保留。连续练习从今天开始计算；今天尚未答题时从昨天开始计算，最多显示 365 天。
- 已提交但未完成整组的答案仍计入统计和错题本；整组完成后才生成完成记录和结算奖励。自由练习的出题单不计入统计。
- 旧版积分、主题、奖励和关卡进度自动兼容，学习统计从更新后首次答题开始，不推算旧版答题历史。

## 积分商店

目前内置三种可直接使用的页面主题：晴空蓝（60 分）、落日橙（100 分）、鸢尾紫（150 分）。兑换后立即应用，可在商店切换已拥有的主题或免费恢复青苔绿。

还没有确定兑换什么时，可以先攒分。在「管理自定义奖励」中填写奖励名称和价格，例如一本书、一次活动或其他约定奖励：

- 支持添加和下架，最多保留 30 个自定义奖励。
- 兑换前明确显示价格、当前余额和兑换后余额；取消不会扣分。
- 自定义奖励可以重复兑换，每次扣分并保留兑换记录。实物和约定奖励需自行安排兑现。
- 主题只能购买一次；余额不足时不能兑换，不会出现负余额。
- 保留最近 300 条积分与兑换记录。下架商品不删除已产生的兑换记录。

积分、通关记录、学习记录、错题、已拥有的主题和奖励清单保存在当前浏览器本地，不含账户或跨设备同步。清除浏览器数据会清除这些记录。无法保存时页面会给出提示；保存写入失败时，答题提交、奖励结算或兑换不会生效，可以在恢复存储后重试。

## 自由练习

常用设置只保留数值范围（10 / 20 / 100 以内）、四种运算、题量（1～200）和一步 / 两步 / 混合题型。「更多设置」里可以调整括号、每行最多题数、0 的参与方式及简单题过滤。括号专项自动切换为两步运算，避免选出无解的题型。

- **数值范围约束操作数、中间结果和最终答案**，例如选择 20 以内，计算过程也不会超过 20。
- 默认隐藏答案；显示或隐藏答案只改变当前题目的显示，不会重新出题。
- 支持复制题目；列数会根据可用宽度自动减少，适配手机和桌面。
- 移除了原先的姓名 / 日期 / 用时填写栏、可编辑卷头、重复快捷按钮，以及不常用的配比设置。高级出题参数仍可通过命令行使用。
- 自由练习不奖励积分。

## 算题逻辑

Python 实现位于 `src/simple_calculate/`，浏览器版本内联在 HTML 的 `sc-engine` 脚本中。二者遵守相同约束：

- 所有数值为非负整数，且不超过配置上限。
- 除法整除、除数不为 0；默认乘法两个因子都在 1～9。
- 默认过滤 ×1、÷1 等简单形式，0 只作为最终答案出现。
- 同一份题目按题面去重；题量不足时明确提示，不会悄悄重复或改变单双运算符题的配比。
- 题面按标准优先级独立回读校验，括号只在计算顺序或数值约束需要时保留。

本次改进了两个边界：

1. **去括号后重新检查实际乘法因子。** `2 × (18 ÷ 3)` 不能省去括号，否则虽然结果仍为 12，学生实际会先计算九九表以外的 `2 × 18`。Python 与浏览器的渲染器、独立校验器同时覆盖此约束。
2. **除法按合法整数对等概率抽样。** 原先等概率选择除数会过度集中于商为 1 的题。现在按各除数对应的合法商数量抽样；表内除法关另外由除数、商均在 2～9 的乘法事实反推题目。

固定种子仍可复现当前版本的题目；抽样改进后不保证与旧版种子输出一致。

## 命令行

要求 Python 3.11 或更高版本，不依赖第三方库。

PowerShell：

```powershell
$env:PYTHONPATH = 'src'
python -m simple_calculate -n 20 --seed 42
```

或安装为命令行工具：

```text
pip install -e .
simple-calculate -n 20 --seed 42
```

常用示例：

```text
simple-calculate -n 30 --ops +-
simple-calculate -n 40 --operators 1 --ops "*"
simple-calculate -n 20 --operators 2 --paren always
simple-calculate -n 30 --max-value 20 --max-result 20
simple-calculate -n 30 --min-value 0 --mul-min 0 --no-exclude-zero-forms
simple-calculate -n 20 --seed 42 --show-answer --out 题目.txt
```

完整选项通过 `simple-calculate --help` 查看。网页版的积分功能独立运行，命令行保留为纯出题工具。

## 验证

在 SimpleCal 目录运行：

```powershell
$env:PYTHONPATH = 'src'
python -m unittest discover -s tests -t tests
```

浏览器引擎和积分逻辑测试需要 Node.js（无 npm 依赖）；未找到时相关测试会明确跳过。可通过 `SC_NODE` 指定路径。设置 `SC_SAMPLE_N` 可调整 Python 批量算题验证规模，默认 20,000。

目前包含 73 项测试：候选集与暴力枚举对齐、范围和优先级约束、单双题型配比、HTML 单文件与离线保证、浏览器 / Python 引擎交叉验证，以及 36 组积分、闯关、兑换、学习和存储行为检查，以及 20 组学生隔离、旧数据迁移与备份恢复检查，以及 16 组专项、提示、推荐和迁移检查。专项题库的全部 72 道题及其 216 步讲解等式另由 Python 独立枚举、求值复核。全部 12 个关卡另抽取 1,200 道题交给 Python 独立校验器复核。

原有页面已实际验证：通关奖励与下一关解锁、错题回顾、输入校验、主题兑换、取消兑换、自定义奖励、刷新恢复、答案切换不换题，以及桌面 / 窄屏布局。
