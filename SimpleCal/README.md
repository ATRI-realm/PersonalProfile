# simple-calculate

面向小学生的四则运算题目生成器。有命令行和网页版两种用法；**答案默认不出**，需要时命令行加 `--show-answer`、网页版点顶栏那个「显示答案」开关。

每道题有一个或两个运算符，可以带括号，满足：

- 出现的**所有数值**（叶子操作数、每一步中间结果、最终结果）都是 `[0, 100]` 内的整数，不出现负数
- 除法除得尽，除数不为 0
- 乘法限制在九九表内（`1×1 … 9×9`）
- 括号只出现在必需处——每处括号都真的改变了运算顺序

完整的设计说明、算法推导与验证结果见 [计划书.md](计划书.md)。

## 快速开始

网页版最省事：**双击 `口算练习.html`** 即可，不用装任何东西（见下）。

命令行则无需安装，直接跑：

```bash
PYTHONPATH=src python -m simple_calculate -n 20 --seed 42
```

或安装为命令行工具：

```bash
pip install -e .
simple-calculate -n 20 --seed 42
```

输出：

```text
  1. 75 + 13 =             2. 87 ÷ 29 =             3. 27 − 24 =             4. 6 × 4 ÷ 2 =

  5. 65 + 0 ÷ 47 =         6. 29 − 16 =             7. 71 + 6 =              8. (14 + 19) ÷ 3 =

  9. 90 − 4 × 8 =         10. 4 × 4 =              11. 48 + 6 − 54 =        12. 3 + 94 =

 13. 27 + 7 × 5 =         14. 3 + 11 =             15. 44 ÷ 44 =            16. 87 − 41 + 14 =

 17. (31 − 16) ÷ 15 =     18. 98 − 37 + 14 =       19. 94 − 13 =            20. 59 + (68 − 31) =
```

加上 `--seed` 就能复现同一份题面；把 `--out 题目.txt` 传进去即可写入文件。加上 `--show-answer` 则连答案一起输出。

## 网页版

**双击 `口算练习.html` 就行**：这是一个自包含的单文件，样式、出题引擎、页面脚本、图标全部内联在里面，没有任何外部依赖。

- 不需要装 Python，不需要起进程，`file://` 直接打开就能用
- 页面**不联网**，全部计算在浏览器本地完成
- 拷给别人时只需给这一个文件，不用带整个目录

页面左边调参数、右边实时出题，改动任何一项都会立刻重新出一份。

- **显示答案** —— 顶栏开关，默认关。开启后每题在等号后面用朱红写出答案；切它只重画卷面，**不会换一批题**。
- **复制题面** —— 把排版好的纯文本放进剪贴板，方便贴进 Word 之类；答案的开与关会跟着一起带出去。
- **复现** —— 状态栏显示本次的随机种子，点一下即可复制；把它填进「更多设置 → 随机种子」就能重现同一份题面。
- **卷头** —— 标题可以直接点着改；姓名 / 日期 / 用时栏可以在「更多设置」里关掉。
- **每行排几题** —— 这是**上限**。窗口不够宽时，列数会自动少一档（而不是把字压小、或让答案折到下一行），面板上会写明实际排了几列。

关于出题逻辑：权威实现在 Python 侧（`src/simple_calculate/`），页面里内联的是它的浏览器移植版。为不让"两份实现"变成"两份会漂移的真相"，浏览器引擎的产出会被成批送进 Python 那份**独立校验器**逐题复核（见 `tests/test_engine_parity.py`），而不是靠"照着抄了一遍"的自觉。

## 常用例子

```bash
# 只要加减法，每行 2 题，写到文件
simple-calculate -n 30 --ops +- --per-line 2 --out 口算.txt

# 只练乘法，并提高乘法的抽样权重（* 要用引号，否则会被 shell 当通配符展开）
simple-calculate -n 40 --operators 1 --ops '*' --weights '*=5'

# 只出带括号的双运算符题（专项练习）
simple-calculate -n 20 --operators 2 --paren always --per-line 2

# 单运算符题占七成，且一道题都不重复
simple-calculate -n 100 --operators 1,2 --ratio 7,3

# 低年级：操作数不超过 20，不允许结果为 0
simple-calculate -n 30 --max-value 20 --mul-max 9 --no-zero-result

# 想出现 0 × n 这类乘法题（默认九九表不含 0）
simple-calculate -n 30 --mul-min 0

# 连答案一起输出（给家长核对用）
simple-calculate -n 20 --seed 42 --show-answer
```

## 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `-n, --count` | 20 | 题目数量 |
| `--ops` | `+-*/` | 参与抽取的运算符，如 `--ops +-` 或 `--ops 加减` |
| `--weights` | 均等 | 各运算符权重，如 `+=3,-=3,*=2,/=2` |
| `--operators` | `1,2` | 每题的运算符个数：`1` / `2` / `1,2` |
| `--ratio` | `1,1` | 与 `--operators` 对应的题量配比，如 `--operators 1,2 --ratio 3,7` |
| `--min-value` | 1 | 叶子操作数下界；要让 0 参与运算，设为 0 并加 `--no-exclude-zero-forms` |
| `--max-value` | 99 | 叶子操作数上界 |
| `--max-result` | 100 | 中间结果与最终结果的硬上界 |
| `--mul-min` | 1 | 乘法因数下界（设为 0 可让 `0 × n` 出现） |
| `--mul-max` | 9 | 乘法因数上界（默认 9 即九九表） |
| `--paren` | `necessary` | `none` 只出无括号题 / `necessary` 括号只在必需处 / `always` 只出含括号的双运算符题 |
| `--no-zero-result` | 关闭 | 加上即禁止结果为 0 |
| `--exclude-trivial` | 开启 | 过滤 `n×1`、`1×n`、`n÷1`、`0⊕0`；用 `--no-exclude-trivial` 关闭 |
| `--exclude-zero-forms` | 开启 | 让 0 只能作为最终结果出现，不参与运算；用 `--no-exclude-zero-forms` 关闭 |
| `--allow-repeat` | 关闭 | 不重复的题面不够时，允许重复以凑满题量（默认会如实报告缺口） |
| `--per-line` | 4 | 每行排几道题 |
| `--seed` | 随机 | 固定随机种子，结果可复现 |
| `--out` | 控制台 | 写入文件（`.txt` / `.md`） |
| `--no-blank-line` | 关闭 | 行与行之间不留空行 |
| `--show-answer` | 关闭 | 加上即连答案一起输出（答案在题干等号右侧） |

完整参数说明（含边界条件）用 `simple-calculate --help` 查看。

## 关于"题量凑不满"

题目是不重复的，而每一类题的题面总数是有限的——默认参数下单运算符题约 1.06 万种，双运算符题的题面空间约 200 万种。请求的题量超过这个上限时：

```bash
$ simple-calculate -n 30000
... 题面 ...
题量不足：1 个运算符的题需要 15000 道，不重复的题面只够 10625 道。可尝试：允许题面重复、放宽数值范围、增加可用的运算符、减少题量。
```

程序不会静默少给，也不会把缺口悄悄摊到另一种题型上。确实需要重复题面时加 `--allow-repeat`。

日常出题（几十到几百道）不会碰到这个上限。

## 跑测试

```bash
python -m unittest discover -s tests -t tests
```

默认采样量可以用环境变量放大，做更大规模的核验：

```bash
SC_SAMPLE_N=100000 python -m unittest discover -s tests -t tests
```

交叉验证那一类测试需要本机有 `node`；找不到时会整类跳过（不把可选工具变成硬依赖）。

## 布局

```text
SimpleCalculate/
├─ 口算练习.html                    网页版：自包含单文件，双击即用
├─ README.md                        本文件
├─ 计划书.md                        设计与验证记录
├─ pyproject.toml                   包与依赖声明、命令行入口注册
├─ src/simple_calculate/
│  ├─ config.py      生成参数
│  ├─ model.py       Node / Problem 数据结构
│  ├─ core.py        两数合法对构造
│  ├─ generator.py   题量分配与算式生成
│  ├─ validate.py    硬约束判定 + 独立优先级求值器
│  ├─ render.py      括号决策与文本渲染
│  └─ cli.py         命令行入口
└─ tests/
   ├─ test_core.py            两张候选表的对称性、边界、与暴力枚举对齐
   ├─ test_generator.py       批量采样、各模式行为、题量配比
   ├─ test_validate.py        优先级求值器与 round-trip
   ├─ test_page.py            单文件页面：自包含性、内联标记、答案开关默认态
   └─ test_engine_parity.py   页面内联引擎 × Python 校验器的交叉验证
```

依赖方向是单向的：`config ← model ← core ← generator ← cli`，`validate` 与 `render` 只依赖 `config` / `model`。校验器**故意不依赖生成器**，所以生成逻辑写错时校验逻辑不会跟着一起错。这几个接口正是网页版接上去的地方，没有为前端改动生成逻辑。

## 本版不做

- 题库持久化、历次出题去重、用户系统
- 打印排版（页面只面向屏幕；浏览器自带的打印能用，但它不是这份交付物的目标）
