# SimpleCal

给小学生使用的离线口算工具：自由练习、算术闯关和积分商店。**双击 `口算练习.html` 即可打开**，不需要安装、不需要服务、不需要联网。发给别人时只需复制这一个 HTML 文件。

## 算术闯关

- 12 个关卡，依次学习加法、减法、20 以内加减、九九乘法、表内除法、百数加减、两步运算、乘除混合、四则和括号。
- 每关 10 道不重复的题，通常答对 8 道通关，最后一关需答对 9 道。不计时。
- 每题提交一次答案，再进入下一题；支持键盘 Enter 和全角数字。答错后显示正确答案，结束时集中回顾错题。
- 通过后解锁下一关。**首次通关奖励 `20 + 5 × (关卡编号 − 1)` 分**，即每关 20～75 分，全部首次通关共 570 分。
- 已通过的关卡可以重玩并更新最好成绩，但不重复发放积分。
- 离开未完成的挑战前会提示；本次答题过程不保存，已获得的积分和通关记录不受影响。

## 积分商店

目前内置三种可直接使用的页面主题：晴空蓝（60 分）、落日橙（100 分）、鸢尾紫（150 分）。兑换后立即应用，可在商店切换已拥有的主题或免费恢复青苔绿。

还没有确定兑换什么时，可以先攒分。在「管理自定义奖励」中填写奖励名称和价格，例如一本书、一次活动或其他约定奖励：

- 支持添加和下架，最多保留 30 个自定义奖励。
- 兑换前明确显示价格、当前余额和兑换后余额；取消不会扣分。
- 自定义奖励可以重复兑换，每次扣分并保留兑换记录。实物和约定奖励需自行安排兑现。
- 主题只能购买一次；余额不足时不能兑换，不会出现负余额。
- 保留最近 300 条积分与兑换记录。下架商品不删除已产生的兑换记录。

积分、通关记录、已拥有的主题和奖励清单保存在当前浏览器本地，不含账户或跨设备同步。清除浏览器数据会清除这些记录。无法保存时页面会给出提示；保存写入失败时，奖励结算或兑换不会生效，可以在恢复存储后重试。

## 自由练习

常用设置只保留数值范围（10 / 20 / 100 以内）、四种运算、题量（1～200）和一步 / 两步 / 混合题型。「更多设置」里可以调整括号、每行最多题数、0 的参与方式及简单题过滤。括号专项自动切换为两步运算，避免选出无解的题型。

- **数值范围约束操作数、中间结果和最终答案**，例如选择 20 以内，计算过程也不会超过 20。
- 默认隐藏答案；显示或隐藏答案只改变当前题目的显示，不会重新出题。
- 支持复制题目；列数会根据可用宽度自动减少，适配手机和桌面。
- 移除了原先的姓名 / 日期 / 用时填写栏、可编辑卷头、重复快捷按钮，以及不常用的配比设置。高级出题参数仍可通过命令行使用。
- 自由练习不奖励积分。

## 算题逻辑

Python 实现位于 `src/simple_calculate/`，浏览器版本内联在 HTML 的 `sc-engine` 脚本中。二者遵守相同约束：

- 所有数值为非负整数，且不超过配置上限。
- 除法整除、除数不为 0；默认乘法两个因子都在 1～9。
- 默认过滤 ×1、÷1 等简单形式，0 只作为最终答案出现。
- 同一份题目按题面去重；题量不足时明确提示，不会悄悄重复或改变单双运算符题的配比。
- 题面按标准优先级独立回读校验，括号只在计算顺序或数值约束需要时保留。

本次改进了两个边界：

1. **去括号后重新检查实际乘法因子。** `2 × (18 ÷ 3)` 不能省去括号，否则虽然结果仍为 12，学生实际会先计算九九表以外的 `2 × 18`。Python 与浏览器的渲染器、独立校验器同时覆盖此约束。
2. **除法按合法整数对等概率抽样。** 原先等概率选择除数会过度集中于商为 1 的题。现在按各除数对应的合法商数量抽样；表内除法关另外由除数、商均在 2～9 的乘法事实反推题目。

固定种子仍可复现当前版本的题目；抽样改进后不保证与旧版种子输出一致。

## 命令行

要求 Python 3.11 或更高版本，不依赖第三方库。

PowerShell：

```powershell
$env:PYTHONPATH = 'src'
python -m simple_calculate -n 20 --seed 42
```

或安装为命令行工具：

```text
pip install -e .
simple-calculate -n 20 --seed 42
```

常用示例：

```text
simple-calculate -n 30 --ops +-
simple-calculate -n 40 --operators 1 --ops "*"
simple-calculate -n 20 --operators 2 --paren always
simple-calculate -n 30 --max-value 20 --max-result 20
simple-calculate -n 30 --min-value 0 --mul-min 0 --no-exclude-zero-forms
simple-calculate -n 20 --seed 42 --show-answer --out 题目.txt
```

完整选项通过 `simple-calculate --help` 查看。网页版的积分功能独立运行，命令行保留为纯出题工具。

## 验证

在 SimpleCal 目录运行：

```powershell
$env:PYTHONPATH = 'src'
python -m unittest discover -s tests -t tests
```

浏览器引擎和积分逻辑测试需要 Node.js（无 npm 依赖）；未找到时相关测试会明确跳过。可通过 `SC_NODE` 指定路径。设置 `SC_SAMPLE_N` 可调整 Python 批量算题验证规模，默认 20,000。

目前包含 69 项测试：候选集与暴力枚举对齐、范围和优先级约束、单双题型配比、HTML 单文件与离线保证、浏览器 / Python 引擎交叉验证，以及 21 组积分、闯关、兑换和存储行为检查。全部 12 个关卡另抽取 1,200 道题交给 Python 独立校验器复核。

页面已实际验证：通关奖励与下一关解锁、错题回顾、输入校验、主题兑换、取消兑换、自定义奖励、刷新恢复、答案切换不换题，以及桌面 / 窄屏布局。

原有 `计划书.md` 保留为出题引擎的历史设计记录；当前使用方式、闯关规则及商店行为以本文和实现为准。
